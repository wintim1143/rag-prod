# 04 — 问答/聊天端点（真实生成 + 引用）

**What to build:** 在检索上下文之上接真实云 LLM 生成回答：`POST /ask`（单轮问答）与 `POST /chat`（多轮对话带历史）。Prompt 要求模型只依据给定块回答并标注 [1]/[2] 引用；未知问题应明确说「资料中没有」，而非编造。响应暂不流式（流式在 09），但响应体携带所用来源块，前端可溯源。

**Blocked by:** 03 — 混合检索 + 本地 cross-encoder 重排

**Status:** done ✅ (2026-08-14)

- [x] `/ask` 返回基于检索块、带引用标注的真实 LLM 回答
- [x] `/chat` 维持多轮历史；对最后一轮用户消息做检索 query 改写以反映对话上下文
- [x] 资料未覆盖的问题产出「资料中没有」的拒答而非幻觉（抽查验证）
- [x] LLM provider 由环境变量配置；用桩 provider 可离线测试
